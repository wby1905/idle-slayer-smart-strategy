# Security Policy

Smart Strategy runs inside the game process and can automate progression or modify client-side effect state. Back up saves before evaluating development builds.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

Update to the newest available release before reporting a security problem.

## Reporting a vulnerability

Do not include save files, account identifiers, purchase records, proxy credentials or full logs containing personal paths in a public issue. Share only the smallest relevant log section.

For a vulnerability that could affect saves, accounts or unintended purchases, use the repository's [private security-advisory form](https://github.com/wby1905/idle-slayer-smart-strategy/security/advisories/new) instead of a public issue. Include the Smart Strategy version, Idle Slayer version, dependency versions from the startup compatibility snapshot and reproducible steps.
